# Hong Kong Wastewater Explorer

[**Open app**](https://liilymiao.github.io/hong-kong-wastewater-explorer/)

[Download](https://github.com/liilymiao/hong-kong-wastewater-explorer/releases/latest/download/project.zip) | [Video](https://liilymiao.github.io/hong-kong-wastewater-explorer/video.html)

Explore monitoring data and download tables, matrices and experimental susceptibility records for further analysis.

| Task | Output |
| --- | --- |
| Annual resistance trends | PHLSB or HA records, trend figures and percentage-point comparisons |
| ARG count matrix | Selected European sewage samples, a 554-gene raw-count matrix and sequencing metadata |
| Genomes and AST data | BV-BRC experimental susceptibility records, genome links and MIC details |
| Sample quality | Hong Kong sewage sample lists, sequencing metrics and assembly QC |
| Match my data | An analysis table from environmental, clinical and area-mapping CSVs |
| Background data | Rainfall, influenza, antimicrobial supply or Global Sewage records |
| COVID-19 monitoring | Hong Kong clinical and wastewater trends, past forecasts and model comparisons |

Download CSVs, figures or complete packages with query settings, source records and checksums. Save a query or copy its link to reopen the same selection. Source definitions and processing details are available in **Data coverage & sources**.

Software 1.6.3 retains the unchanged dataset snapshot metadata from 1.6.2.

Version **1.6.3** includes Python **1.5.3**, scientific configuration **1.1**, frozen results, video and eight subtitle tracks.

[Python course package](https://github.com/liilymiao/hong-kong-wastewater-explorer/releases/latest/download/course-python.zip) | [English report](https://github.com/liilymiao/hong-kong-wastewater-explorer/releases/latest/download/report.pdf)

The Python course entry follows the research question, a reproducible historical prediction, model comparison, patterns and export. The package includes a ten-minute demonstration outline and implementation-to-test mapping.
