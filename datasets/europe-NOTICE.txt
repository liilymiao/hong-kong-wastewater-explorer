The application extracts factual counts and sample fields from Supplementary
Data 1 and 3. Column locations are indexed to the dictionary in Supplementary
Data 5. Changes are limited to numeric parsing, ISO date formatting and an
explicit key-based metadata connection. No count is normalized, imputed,
averaged or otherwise numerically modified.

235 matrix rows represent 235 distinct ENA biological samples. There are 554
ResFinder gene columns and 130,190 count cells. The matrix keys match 235 metadata
runs directly. Across those 235 biological samples, the complete metadata lists
274 associated runs. All metadata contains 278 runs from 238 biological samples;
three biological samples have no count row in this matrix. Associated runs are
not assumed to have been individually included in a given matrix count.

Unit: raw gene counts. The count is not copies/L, a clinical proportion or a
normalized cross-sample abundance. Clinical susceptibility pairing is absent.
