RUN THE APPLICATION
Use Python 3.12. Extract PythonCode20261116.zip, then open a terminal in the
extracted MATH7005 Course folder.

macOS / Linux:
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock.txt
.venv/bin/python launch.py --port 8501

Windows:
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
.venv\Scripts\python.exe -X utf8 launch.py --port 8501

Open http://127.0.0.1:8501 and select Course demo.
Dependency installation requires an internet connection. The application
uses included data and results after installation; model reruns are not
required for the demonstration. Stop the application with Ctrl+C.

VERSION AND CONTENTS
Python 1.5.4; release v1.6.4; scientific configuration 1.1.
The COVID-19 analysis uses the frozen snapshot dated 23 October 2026.
The eight-page report is included both separately and inside the code ZIP.
This distribution updates report formatting and replaces machine-specific
source paths with portable metadata. Python source, CSV data, configuration
and numerical results are unchanged. The original Markdown and HTML report
remain as generated analysis records.
